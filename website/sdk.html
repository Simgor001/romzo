@romzo/client

TypeScript SDK for the romzo/v1 protocol. Its only dependencies are WebCrypto and WebSocket.

romzo/v1 协议的 TypeScript SDK。只用 WebCrypto 与 WebSocket，零运行时依赖。

Build from source

从源码构建

The SDK lives in packages/romzo-client. From the repository root:

SDK 位于 packages/romzo-client。在仓库根目录执行：

npm ci
npm run build -w @romzo/client

The build is ESM with strict TypeScript types.

构建产物为 ESM，带严格模式 TypeScript 类型。

Concepts

概念

  • Room — a 10-character room code. The host signs the room descriptor with the host key pair.
  • 房间——10 位房间码，房主持 host 密钥对 descriptor 签名。
  • Tickets — admission tickets authenticate the WebSocket (60 seconds, single handshake). Recovery tickets restore a room after a crash or restart.
  • 票据——admission 票据用于 WebSocket 认证 （60 秒、单次握手）；recovery 票据在崩溃或重启后恢复房间。
  • Channels — discovery / lobby / game. Subscribers receive join / leave / receive frames.
  • 通道——discovery / lobby / game，订阅后收到 join / leave / receive 帧。

Host: create, confirm, connect

房主：创建、确认、连接

import { createRoom, RelaySession } from '@romzo/client';

const room = await createRoom('https://romzo.net', roomOptions);

const url = room.descriptor.origin.replace(/^http/, 'ws') + '/ws';
const session = await RelaySession.connect(url, room.admission, room.transport);

session.on('join', (_p, { channel, peer, key }) => { /* peer key for E2E crypto */ });
session.on('receive', (value, { channel, peer }) => { /* a peer's payload */ });
session.on('close', () => { /* reconnect with the recovery ticket */ });

await session.subscribe('game');

session.on('receive', (value, { channel, peer }) => { /* 他人 send 的负载 */ });
session.on('close', () => { /* 终端 error 帧或传输断开，用 recovery 票据重连 */ });

await session.subscribe('game');

Relays with CREATE_AUTH=password take { password } as the third argument of createRoom.

开了 CREATE_AUTH=password 的中继， createRoom 第三个参数传 { password }。

Guest: join from an invite

访客：凭邀请加入

import { joinRoom, RelaySession } from '@romzo/client';

const joined = await joinRoom('https://romzo.net', 'ABCD2345EF');
const url = joined.signedDescriptor.descriptor.origin
  .replace(/^http/, 'ws') + '/ws';
const session = await RelaySession.connect(url, joined.admission, joined.transport);
await session.subscribe('lobby');

joinRoom verifies the descriptor, config hash and host signature before requesting admission.

joinRoom 在申请 admission 前核对 descriptor、configHash 与宿主签名。

Crash recovery

崩溃恢复

Keepalive responses update session.currentRecovery() automatically. Persist three values — signedDescriptor, transport, recovery — to restore the room after a restart:

keepalive 应答自动更新 session.currentRecovery()。 持久化三个值——signedDescriptor、transport、 recovery——即可在中继重启后恢复房间：

import { restoreSession, RelaySession } from '@romzo/client';

const restored = await restoreSession(
  saved.signedDescriptor, saved.recovery, saved.transport);
const session = await RelaySession.connect(wsUrl,
  restored.admission, restored.transport);
// resubscribe and sync history in the envelope layer

The SDK leaves these to you

以下部分由调用方负责

  • Reconnection. After a drop, reconnect with the recovery ticket, resubscribe and sync history.
  • 重连。断线后凭 recovery 票据重连、重新订阅并同步历史。
  • Key storage. Generated keys are extractable for export and recovery. Pick a protected storage and a clearing policy.
  • 密钥存储。生成的密钥可导出（extractable），用于 导出与恢复。存储保护与清除策略由应用选择。
  • Rules. The SDK does not interpret game options. Validate them with the validateOptions callback.
  • 规则。SDK 不解释桌游 options，通过 validateOptions 回调校验。
